Ironpulse — движок промышленной телеметрии и обнаружения аномалий в реальном времени. Опрашивает датчики по протоколу Modbus TCP, сохраняет показания как временные ряды (в памяти и на диске через write-ahead log), обнаруживает аномалии с помощью нескольких статистических стратегий (z-score, EWMA, CUSUM) с голосованием по кворуму, и отдаёт результат через REST + WebSocket API на этот дашборд в реальном времени.

Технологии: C++20 (ядро, Modbus-клиент, хранилище, аналитика, REST и WebSocket API), JavaScript (дашборд), Python (симулятор Modbus-устройств для демо), Docker/Docker Compose и nginx (развёртывание).
